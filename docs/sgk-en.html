Drop the Excel in, sign in, leave it running.

Prepare the Excel. Four columns are enough: title, tax number, base, Bağ-Kur withholding. If the folder holds one Excel file it uses that one whatever it is called; with several it asks which; with none it creates an empty template itself.

Sign in yourself. Chrome opens and goes to the SGK page. You enter the user code and password; the program does not store your session. When you are in, you press a key and the run starts.

The program enters. For each producer it queries the tax number, writes the base and withholding into the fields, saves, and moves on. A base of 1,000,000 TL or more is split into two records, so a single line above the limit is not rejected.

See the result. At the end it says how many records went through and how many failed, lists the failures with tax number and message, and offers one more pass if you want it. Temporary failures such as a dropped session are recovered in that pass.
