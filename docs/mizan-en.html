Connect, pull, check.

Connect. You enter your Luca member number, user name and password once; they stay in a file on your own computer and go nowhere. When the browser opens you fill in the user-name field yourself; the program does not type your password.

Pick the client. The client list comes with a year and class filter and a search box. Choose a single client, give a date range (leave it blank for the full year), or take reports for every filtered client one after another.

Check. The downloaded trial balances are scanned against the rule list. Every breach is listed with the account code, account name and rule number; the OK, ERROR and WARNING counters sit on top. The same breach is not written twice.

Take the report. The result is written to Excel with a per-rule summary showing how many accounts each rule fired on. You can hand the report to the client as it is.

The rules
come built in.

The rule list is defined inside the program; the same 12 rules run on every check. Rules can be added and removed, so your office's habit ends up in the program.

Mismatch per account · no duplicate findings
