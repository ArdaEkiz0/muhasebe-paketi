Transparency: SBOM and security scanning

Every third-party component inside the application (libraries and native runtimes included) is published in the SBOM.json list. The list is CycloneDX 1.5 and is extracted directly from the shipped package: each component’s version, licence and dependencies, plus the SHA-256 of the native runtime files.

You can also inspect the files with independent security engines; the links open VirusTotal by the file’s own SHA-256:

  • Package installer · VirusTotal
  • Portable package · VirusTotal

VirusTotal only scans files that are submitted to it; a freshly released version may show Item not found — that is not a scan result, it means the record does not exist yet. Meanwhile you can verify the file yourself: in PowerShell, Get-FileHash .\Muhasebe-Paketi-kurulum.exe -Algorithm SHA256 must match the value in SHA256SUMS.txt exactly.

Installation

  1. Download the installer above and run it.
  2. Follow the wizard. The package installs all three modules into one folder (%LOCALAPPDATA%\Programs\Muhasebe Paketi); no administrator rights needed.
  3. The program asks for a product key (licence) on first use; buying runs through a person. Send your package choice to info@muhasebepaketi.com.tr or +90 546 208 38 54; the licence is assigned to your device from the server — there is no key to type.

If your antivirus flags the file (ESET, Defender)

The application is not digitally signed yet, so some antivirus products raise a false positive on a packaged, unsigned program and may quarantine it. The file is clean; its only source is the download link on this page.

ESET: Settings → Virus and spyware protection → Exclusions → Add path: %LOCALAPPDATA%\Programs\Muhasebe Paketi. Then add KDV Kontrol.exe under HIPS → Excluded applications. Restore the quarantined item or run the installer again.

Microsoft Defender: Windows Security → Virus & threat protection → Manage settings → Exclusions → Add exclusion → Folder: %LOCALAPPDATA%\Programs\Muhasebe Paketi.

We also reported the false positive to the vendors; once their signature is updated you can remove the exclusion. If your antivirus still blocks it, send us the detection name and time so we can add it to our report: info@muhasebepaketi.com.tr.

If Windows shows a warning

The application does not have a code signing certificate yet, so Windows SmartScreen may show an “unknown publisher” warning. If you downloaded the file only from the link on this page, you can continue: More info → Run anyway.

Updates

You can check for updates from inside the application. Every update package passes three gates: the Ed25519 signature, then the SHA256SUMS.txt digest, and finally the file's own SHA-256 digest. If verification fails, the update is not installed.

Uninstalling

Control Panel → Programs and Features → Muhasebe Paketi → Uninstall. Alternatively run unins000.exe from the installation folder. Uninstalling removes the application and its files completely; the invoice and report files on your computer are untouched.
